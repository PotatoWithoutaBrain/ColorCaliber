# ColorCaliber
## Deskripsi Game
ColorCaliber adalah game roguelike 2D top-down bullet hell yang berbasis level. Player berusaha untuk bertahan hidup dari ronde-ronde yang dipenuhi dengan tantangan, termasuk musuh, serta fitur unik game ini, yaitu Colour Grids. Setiap Colour Grid memiliki fitur uniknya sendiri, seperti Colour Grid merah yang menyakiti player, dan warna lain. Setiap ronde memiliiki pattern grid yang berbeda, sehingga player harus beradaptasi dengan lingkunganya. Player juga dapat meng-upgrade senjata dengan mengumpulkan sejumlah Colour Grid biru. Skor akan dicatat berdasarkan seberapa cepat semua ronde diselesaikan.
